# อ่านบัตรประชาชนด้วย ACS บน Mac

ใช้เครื่องอ่าน **แบบสัมผัสชิป (contact)** ที่รองรับ PC/SC เช่นตระกูล ACR39U เสียบบัตรในช่องอ่านชิป เครื่องอ่าน NFC อย่างเดียวไม่ใช่อุปกรณ์ทดแทน

1. เสียบเครื่องอ่านเข้ากับ **Mac ที่รัน Next.js server** และเสียบบัตรประชาชน
2. ตรวจเครื่องอ่านด้วย `python3 scripts/read-thai-id.py --list` (คำสั่งนี้ไม่อ่านข้อมูลส่วนบุคคล)
3. เปิดผู้กู้ยืม → เพิ่ม/แก้ไข → อ่านบัตรประชาชน
4. ตรวจชื่อ เลขบัตร รูป และรายละเอียดจากชิป แล้วกดบันทึกผู้กู้ยืม

สคริปต์ใช้ Python 3 และ PC/SC framework ที่มากับ macOS ไม่ต้องติดตั้ง Python package เพิ่ม หากไม่พบเครื่องอ่าน ให้ตรวจสอบรุ่นและไดรเวอร์จาก [ACS](https://www.acs.com.hk/en/drivers/)

ข้อมูลที่อ่าน: เลขบัตร ชื่อไทย/อังกฤษ วันเกิด เพศ ที่อยู่ วันที่ออกบัตร วันหมดอายุ ผู้ออกบัตร และรูป JPEG ตามฟิลด์ชิปที่รองรับ ไม่อ่านรหัสเลเซอร์หลังบัตร

ข้อมูลยังเป็นร่างจนกดบันทึก ข้อมูลชิปเก็บในฐานข้อมูลรวม ส่วนรูปเก็บใน private/borrower และเรียกผ่าน API ผู้กู้ยืม อ่านได้จาก View ผ่านบัญชีที่เข้าสู่ระบบ ข้อมูลอ่านบัตรลงลายเซ็นผูกกับผู้ใช้และหมดอายุใน 30 นาที ห้ามเปลี่ยนเลขบัตรก่อนบันทึก หากเปลี่ยนเลขบัตรของรายการเดิมโดยไม่ได้อ่านชิปใหม่ ระบบล้างหลักฐานชิปเดิม

การอ่านชิป **ไม่ใช่** การตรวจตัวบุคคลด้วยใบหน้า/การตรวจสถานะบัตรกับกรมการปกครอง และไม่ทำให้ KYC ผ่านโดยอัตโนมัติ

หากย้าย Next.js ไป cloud เครื่องอ่าน USB ที่อยู่บน Mac ของเจ้าหน้าที่จะเข้าถึงไม่ได้ ต้องเพิ่ม local companion service บน Mac และการจับคู่ที่ปลอดภัยก่อนใช้งาน รูปแบบปัจจุบันสำหรับ server ที่รันบน Mac เครื่องเดียวกับเครื่องอ่าน

อ้างอิงโปรโตคอล: [ThaiNationalIDCard APDU](https://github.com/chakphanu/ThaiNationalIDCard/blob/master/APDU.md) และชนิดข้อมูลจาก macOS SDK PCSC.framework/Headers
